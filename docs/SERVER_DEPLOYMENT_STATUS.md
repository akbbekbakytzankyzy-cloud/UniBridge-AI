# UniBridgeAI: состояние сервера

Последнее подтверждённое состояние: 22 ноября 2026. Этот документ описывает фактическое развертывание на VPS, а не обещание готового публичного сервиса. Секреты, пароли, приватный SSH-ключ и API-ключи в Git не включаются.

## Сервер и развертывание

- VPS PS Cloud, Ubuntu 24.04 LTS, проект `kz-uni-1` (ID 20529), имя ВМ `unibridge-api-01`.
- Репозиторий развернут в `/opt/unibridge`, ветка `feature/timetable-gradebook`, ревизия `4862e2d`.
- Установлены Node.js 24, Nginx, Docker и Docker Compose.
- PostgreSQL 17 с pgvector запущен в Docker и привязан к `127.0.0.1:5432`; база не выставлена напрямую в интернет.
- Миграции базы применены: 10 миграций.
- Frontend production build собран на VPS.
- API и Nginx оформлены как systemd-службы; при проверке обе службы и Docker были `active`.
- Nginx раздаёт production UI из `/opt/unibridge/apps/web/dist`, проксирует `/api/` на API `127.0.0.1:3001` и перенаправляет HTTP на HTTPS.
- Публичный origin — `https://80.247.203.210`; `APP_ORIGIN` уже указывает на него. HTTPS health endpoint вернул `{"status":"ok"}`, UI открылся снаружи, `/api/auth/options` вернул `registration: true`.
- TCP 443 доступен извне. TCP 22 для SSH оставлен без изменений. Путь ACME на порту 80 доступен для проверки сертификата.
- Выпущен короткоживущий сертификат Let's Encrypt для IP `80.247.203.210` (истекает 28 ноября 2026). Автоматическое продление через snap systemd timer включено; тестовый ACME-запрос прошёл.
- Регистрация включена в настройках сервера. Для нового аккаунта доступна роль студента; преподавательскую роль должен создать администратор.

## Что пока не работает для пользователя из интернета

1. **Облачный ИИ не подключён на сервере.** `OPENROUTER_API_KEY` в серверном env пуст. Модели и провайдер заданы как конфигурация, но реальные запросы к OpenRouter не пройдут без ключа. Ollama и локальные модели на VPS не устанавливались.

## Интеграции и данные

- **DU/LMS/myDU:** сервер не подключён к API университета и не импортирует данные из этих систем автоматически. Наличие данных в профиле DU не означает, что UniBridge их прочитает.
- **OneDrive:** код интеграции есть, но переменные Microsoft Entra (`MS_CLIENT_ID`, `MS_TENANT`) пусты. Вход и синхронизация Microsoft Graph поэтому не настроены.
- **ResearchGate, Scopus и LinkedIn:** подключений и автоматического импорта на сервере сейчас нет.
- **База:** чистая, без импортированных профилей и академических данных пользователей. Пароль БД и ключ шифрования сгенерированы на VPS и хранятся вне Git в `/etc/unibridge/unibridge.env` с ограниченными правами.

## Что блокирует запуск и следующие шаги

| Что сделать | Что разблокирует |
| --- | --- |
| Добавить OpenRouter API key в защищённый env на VPS и перезапустить API | Облачный чат и задачи ИИ, использующие OpenRouter; расходы будут списываться по тарифам провайдера |
| Зарегистрировать приложение Microsoft Entra и задать client ID/tenant | OneDrive OAuth и синхронизация выбранной папки пользователя |
| Получить разрешённый способ интеграции с DU/LMS либо использовать поддерживаемый импорт файлов | Подтверждённый импорт данных DU/LMS; простой ввод пароля пользователя в UniBridge для чтения сторонних сайтов не реализован |

HTTPS и публичный health endpoint проверены. Следующий шаг — проверить регистрацию и основные сценарии уже через публичный адрес; TLS включён, однако остальные требования production-hardening остаются актуальны.

## Важное о расходах

ВМ тарифицируется PS Cloud пока работает согласно настройкам проекта/услуги. Остановка или пауза сервера снижает/приостанавливает часть расходов по вычислительным ресурсам согласно правилам провайдера, но отдельные ресурсы (например, диски или плавающий IP) могут тарифицироваться отдельно. Перед долгой паузой проверить детализацию расходов в консоли PS Cloud.
