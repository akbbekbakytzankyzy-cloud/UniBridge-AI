# UniBridgeAI: состояние сервера

Последняя проверка деплоя: 24 ноября 2026. Проверены версия приложения, доступность сайта/API и состояние регистрации; прочие интеграции ниже не перепроверялись в эту дату. Этот документ описывает фактическое развертывание на VPS, а не обещание готового публичного сервиса. Секреты, пароли, приватный SSH-ключ и API-ключи в Git не включаются.

- VPS PS Cloud, Ubuntu 24.04 LTS, проект `kz-uni-1` (ID 20529), имя ВМ `unibridge-api-01`.
- Репозиторий API развернут в `/opt/unibridge`, тег `v0.4.7`, ревизия `fc0012d` (detached HEAD), с production hotfix для корректного IP за локальным Nginx. Веб-сборка из коммита `68b4571`.
- Установлены Node.js 24, Nginx, Docker и Docker Compose.
- PostgreSQL 17 с pgvector запущен в Docker и привязан к `127.0.0.1:5432`; база не выставлена напрямую в интернет.
- Миграции базы применены: 10 миграций.
- Frontend production build `v0.4.7` успешно собран на VPS.
- API и Nginx оформлены как systemd-службы; после деплоя обе службы active, контейнер PostgreSQL healthy.
- Nginx раздаёт production UI из `/opt/unibridge/apps/web/dist`, проксирует `/api/` на API `127.0.0.1:3001` и перенаправляет HTTP на HTTPS.
- 24 ноября веб-сборка заменена на обновлённую; предыдущая сохранена в `/opt/unibridge/apps/web/dist.backup-68b4571`. Главная страница, JS/CSS и `/api/health` проверены: HTTP 200.
- Включён `trust proxy=loopback` для production API: Nginx соединяется с API через `127.0.0.1`, а rate limiting теперь получает клиентский IP из `X-Forwarded-For` от доверенного локального прокси.
- Ollama `0.40.17` установлен как включённая systemd-служба. Загружена `qwen3:1.7b` (1,4 ГБ); генерация проверена на VPS. Ollama слушает только loopback `127.0.0.1:11434`, наружу порт не открыт.

## Что пока не работает для пользователя из интернета

1. **Ресурсы локальной модели ограничены.** VPS имеет 1 vCPU и 4 ГБ ОЗУ без GPU. Проверена только чат-модель `qwen3:1.7b`; генерация будет заметно медленнее облака. Модели `qwen3:4b` и `bge-m3` не установлены, поэтому локальные задачи, жёстко настроенные на них (например, embeddings), не проверены.

## Интеграции и данные

- **DU/LMS/myDU:** сервер не подключён к API университета и не импортирует данные из этих систем автоматически. Наличие данных в профиле DU не означает, что UniBridge их прочитает.
- **OneDrive:** код интеграции есть, но переменные Microsoft Entra (`MS_CLIENT_ID`, `MS_TENANT`) пусты. Вход и синхронизация Microsoft Graph поэтому не настроены.
- **ResearchGate, Scopus и LinkedIn:** подключений и автоматического импорта на сервере сейчас нет.
- **База:** чистая, без импортированных профилей и академических данных пользователей. Пароль БД и ключ шифрования сгенерированы на VPS и хранятся вне Git в `/etc/unibridge/unibridge.env` с ограниченными правами.

## Важное о расходах

ВМ тарифицируется PS Cloud пока работает согласно настройкам проекта/услуги. Остановка или пауза сервера снижает/приостанавливает часть расходов по вычислительным ресурсам согласно правилам провайдера, но отдельные ресурсы (например, диски или плавающий IP) могут тарифицироваться отдельно. Перед долгой паузой проверить детализацию расходов в консоли PS Cloud.
